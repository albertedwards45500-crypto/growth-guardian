# 成长宝前端

在此目录执行 `npm install`，然后 `npm run dev`。默认开发服务将 `/api` 转发至 `http://127.0.0.1:8300`；后端启动方式见 `../backend/README.md`。

登录后可进入“成长顾问”（`/advisor`），回顾当前宝宝的成长、饮食记录，筛选辅食候选或查询已审核知识。示例问题只填写表单，点击“开始整理”才发出请求。页面显示来源编号、缺失信息、风险和模型回退状态；切换宝宝会清空问答并取消等待。问答不写入浏览器持久存储，服务密钥仅在后端配置。

知识检索取决于后端开关、独立Embedding服务和已审核资料；页面的“已配置”标记不代表知识集合非空。接口与边界见 `../backend/docs/advisor.md`。

运行 `npm test` 执行离线测试；`npm run build` 检查类型并打包。浏览器联调可临时指定独立后端，避免接触真实数据或模型：

```powershell
$env:API_PROXY_TARGET = 'http://127.0.0.1:8311'
npm run dev -- --host 127.0.0.1 --port 5177
```

该设置只改变开发代理。测试后端应使用独立测试数据库并关闭智能体/RAG、清空模型和Embedding密钥；不要指向真实数据库进行演示数据测试。
