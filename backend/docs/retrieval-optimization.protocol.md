# 候选召回优化：本轮固定评测协议

2026-10-23，在本轮云端比较开始前写入。仅公开问题、公开pending资料和非医学合成夹具；不改正式索引、`.env`或启用RAG。

## 固定策略

- baseline：沿用TopK=3、余弦最低0.55。
- expanded：仅扩大送给既有模型的候选池到TopK=5、最低0.45，不授予自动引用权。
- hybrid：与expanded相同的向量候选，外加中文二元字组/英文数字词的TF-IDF字面排序，以RRF常数60融合，最多5个候选。不使用试题专用词表、同义词硬编码或额外模型。
- 两个检索分支均复用审核、主题、月龄和日期过滤；字面扫描最多200段，超限失败关闭，不静默只扫部分资料。正式默认仍为baseline。
- 模型仍最多选3个本次候选ID，服务端原文引用校验、安全分流、过敏排除和工具权限保持不变。

## 数据与选择顺序

原17题与30题挑战集共47题已经观察过，均作为开发集，不再称未见过的保留集。新增24条合成验证问题（12正例、12无资料/边界例），在策略选择前写入文件并记录哈希；不能根据本轮验证结果反复改策略或标签。这些题是开发者合成标签，并非独立专家或医学验证。

先在47题上运行baseline、expanded、hybrid完整API/模型链路；结构、安全、无资料表现及精确文献选择不得弱于baseline，再按最终命中、精确选择排序。平局优先baseline，其次expanded、hybrid，以较简单策略为先。选择固定后，只对新增24题运行baseline及选中策略各一次；结果不用于重新挑选策略。本轮之后这24题视为已经消费的验证集。

同一进程内复用相同文本的向量，控制服务输出波动；缓存只在内存，退出即清除。每个策略只运行一次模型，不能声称模型稳定性或医疗安全得到保证。结构或安全失败会停止后续比较；最多260次模型请求，预算达到上限不再调用云端。

机器报告区分开发集命中、精确选择、无资料准确情况和新验证集结果。即使结果全通过，也不表示公共草稿已经获得真实内容审核；正式启用仍需审核人与有效期等准入条件。
